# 默认文献选择与方向生成修复

相关文献默认纳入即为正常使用路径。用户不需要移除再添加，也不需要逐篇手动确认，才能生成方向。

## 排查结果

读取已有脱敏记录，最近两次 DeepSeek 方向请求均返回 HTTP 200。这只能说明服务商返回了内容，不能证明内容格式和引用检查通过；记录没有保存原始响应，因此不能断言用户那次失败对应哪一项校验。

代码中确认存在整批校验问题：一个方向的引用错误会使其他有效方向一起丢失，前端统一显示“无法生成有文献支撑的方向”。离线测试已复现并修复。格式、额度或材料问题也可能触发旧提示，不能据此判断用户选错了文献。

## 修改内容

- 模型输入采用简短文献／来源编号，再精确映射回内部来源；不靠模型复写长编号。
- 独立校验每个方向，保留有效选项。未知来源和文献／证据不对应的方向继续拒绝。
- 区分材料缺失、文本额度不足、格式错误、引用错误、模型服务错误和调用额度用完。页面显示原因和相应操作，不展示内部校验代码。
- 同一材料的重试失败时保留上一组有效方向；部分有效结果也能重试，仍受共享预算和重试次数限制。
- 摘要缺失时可读取用户已上传的本地 PDF，复用文档缓存并计入全文处理额度。方向阶段没有增加自动远程 PDF 下载。
- 诊断只记录静态类别、数量及材料覆盖统计，不记录 Key、模型原始响应或文献正文。

## 使用

重启 Streamlit 后，默认保留相关文献，点击生成方向即可。已有项目可先保存并在开始页导入；重新生成仍会消耗模型调用额度。若提示没有可读摘要或正文，返回文献页上传本地 PDF 或补充检索；额度耗尽时先保存项目。

## 验证范围

150 项离线测试通过，其中新增 13 项方向回归测试。覆盖不修改默认选择的完整流程、有效与无效方向混合返回、错误引用、JSON 错误、材料缺失、额度不足、本地 PDF 与项目恢复、重试缓存和前端错误提示。编译与差异空白检查通过。

本轮未发起真实模型、文献检索或下载请求，没有使用用户的 Key 进行付费复测。真实主题上的方向质量仍需实际运行检验。
