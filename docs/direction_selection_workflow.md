# 当前使用流程：相关文献 → 方向多选 → 一份综述大纲

这是本轮根据真实使用反馈调整后的流程。原先的逐篇必须确认、默认展示所有候选的设计已被替换。

## 打开方式

```powershell
Set-Location 'path/to/academic-research-agent'
$env:PYTHONIOENCODING='utf-8'
$env:MOCK_MODE='0'
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```

更新后建议重启应用并开始一次新研究。以前下载的项目仍可通过开始页导入。API 厂商、模型、用户自己的 Key 和“测试连接”流程保持原有方式；测试连接与正式研究都会按供应商规则计费。离线演示不调用付费 API，也不证明真实检索质量。

## 实际操作

1. **提出研究问题。** 写出研究对象、关注的问题和必要范围，例如“医学问答中的 RAG 幻觉控制：比较方法、评价指标与适用边界”。此处仅是输入示例，没有声称已为该主题完成真实检索。
2. **查看相关文献。** 目标至少 5 篇，正常页面只展示直接命中或具有实质相关性的论文。每篇显示标题、年份、相关理由和原文／DOI／开放全文链接。摘要和本地 PDF 上传按需展开。未命中、无法判断的候选保留在技术记录与导出中，不铺在主列表。
3. **保留或移除文献。** 相关文献默认勾选，无须逐篇确认。取消勾选即可移除；继续检索时会保留移除决定。点击“生成可选话题与方向”进入下一步。
4. **多选话题和方向。** AI 基于保留文献的摘要归纳 5–10 个可组合的综述子主题；摘要缺失时可使用用户已上传的本地 PDF。每个给出说明、研究问题及支撑文献。用户可以多选，至少选一个，再点击“根据所选方向生成一份大纲”。此时才开始针对所选方向进一步处理全文／摘要材料。
5. **得到一份整合大纲。** 结构包含问题与范围、检索与选择、概念框架、所选方向的主题比较、分歧与边界、未来问题和结论。所选方向对应主题节点，事实性观点关联来源。默认展示正文结构和参考链接，原文摘录、内部 ID、检查 JSON 不再附在主页面底部。
6. **修改和导出。** 可修改标题、顺序、观点与写作任务；也可返回重新选择方向。支持导出大纲、证据卡片 CSV、文献决定 CSV 和 `project.json`。后者能在文献结果、方向选择或大纲阶段恢复，保留累计预算，不包含 Key 或 SDK 客户端。

## 数量不足与失败处理

- 默认初检不足时自动补充 1 轮来源检索；总补检索上限仍为 2 轮，共享原来的请求、模型和 token 预算。没有无限检索。
- 仍不足 5 篇时明确显示数量不足。用户可使用已有文献生成方向，或在剩余额度内继续检索、调整问题；不会用未命中或无法判断的论文凑数。
- 5–10 个方向是目标。返回并通过引用检查的选项不足 5 个时仍可使用；这不代表已经证明文献在学术上只能支持这些角度。不制造同义选项。
- 默认保留文献是正常用法，不需要先取消再勾选。每个方向单独校验，错误引用不影响其余有效方向；不放行未知来源或与文献不对应的引用。
- 方向失败时区分材料缺失、格式或引用校验失败、模型服务错误和调用额度不足。保留文献并提供额度内重试、返回或结束；同一材料重新生成失败时保留上一组有效选项。不会自动切换 mock 并显示成功。详见 [方向生成修复](direction_generation_fix.md)。
- 多选方向后生成的是一份整合大纲。更换方向会生成对应的新版本；相同方向下更新证据会保留用户修改，并移除失效引用。旧版本和历史保留在项目中。
- 摘要无法说明的实验细节不会当作已知事实。需要补证据的位置仍保留为写作任务或缺口；连贯性与科学完整性没有独立自动验证。

## CLI

```powershell
.\.venv\Scripts\python.exe main.py
# 恢复项目：
.\.venv\Scripts\python.exe main.py --project 'C:\path\project.json'
```

文献页选择使用当前文献；输入要移除的编号，用 `+编号` 恢复，逗号分隔。方向页输入多个编号，例如 `1,3,5`，随后生成一份整合大纲。任一阶段可选择保存项目。

## 验证范围

本轮使用离线合成数据、SDK 替身及 Streamlit AppTest 验证，没有调用用户的付费模型、公开文献接口或下载嵌入权重。测试覆盖默认保留、隐藏未命中／未判断候选、有限补检索、移除决定保留、多选后的单份大纲、方向—文献映射、错误引用拒绝、模型失败不伪造选项和方向阶段项目恢复。

此前 DeepSeek 的小额连接测试不等于本轮新流程的真实质量验证。真实方向的学术价值、提取准确率和端到端耗时仍需真实主题检验，未声称已经获得质量或速度基准提升。
